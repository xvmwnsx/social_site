# Social Site (Bookmarks)

Веб-приложение на **Django 5.1** — основа социальной платформы для обмена закладками и изображениями. Сейчас реализован модуль управления аккаунтами и профилями

## Технологии

| Компонент | Технология |
|-----------|------------|
| Backend | Python, Django 5.1.5 |
| База данных | SQLite |
| Аутентификация | Django Auth + кастомный backend по email |
| Шаблоны | Django Templates |
| Стили | CSS |
| Медиафайлы | `ImageField` (Pillow) |
| Email | Console backend (для разработки) |
| Админка | Django Admin |

## Функциональность

### Реализовано

- **Регистрация** — username, имя, email, пароль с подтверждением; автоматическое создание профиля
- **Вход / выход** — стандартные маршруты `django.contrib.auth.urls`
- **Вход по email** — кастомный `EmailAuthBackend`
- **Личный кабинет (Dashboard)** — страница для авторизованных пользователей
- **Редактирование профиля** — имя, фамилия, email, дата рождения, фото
- **Смена и сброс пароля** — встроенные view Django
- **Админ-панель** — управление профилями пользователей
